# Repository guidance

- Treat each skill's `SKILL.md` as its source of truth.
- Keep skills portable across agent harnesses. Put harness-specific metadata in
  `agents/` rather than in the skill instructions.
- Preserve third-party notices and license files when changing incorporated
  material.
- Run the repository tests and the skill validator before publishing changes.
- Apply `de-ai-ify` to human-facing documentation and publication text.
- Use ASCII punctuation in maintained prose. Do not alter verbatim third-party
  licenses, quoted source material, code, or mathematical notation.
